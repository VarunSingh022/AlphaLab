# AlphaLab Configuration Files

The files in this directory are reference configurations demonstrating how an AlphaLab project may be organized.

At present, AlphaLab does **not** automatically consume these configuration files. They serve as examples for users building research pipelines and production deployments.

## Files

| File | Purpose |
|------|---------|
| development.toml | Local development environment |
| research.toml | Quantitative research configuration |
| paper_trading.toml | Paper trading environment |
| production.toml | Production deployment example |
| logging.toml | Logging configuration |
| examples/strategy.toml | Example strategy configuration |

These files are intended as templates and may be customized to suit individual workflows.
