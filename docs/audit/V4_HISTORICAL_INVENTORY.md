# AlphaLab v4.0 Historical Inventory

Generated by `docs/audit/scripts/historical_inventory_v4.py` from the classification
it holds; `tests/regression/test_every_adr_deferral_is_classified.py` fails when an ADR
or the CHANGELOG states an item this inventory does not classify, or when this file
is stale. Do not edit it by hand.

The pre-v4 ledger (`PRE_V4_COMPLETION_LEDGER.yaml`) already classified ROADMAP's
boundaries and optional list (v3.10) and the release ADRs' known limitations and
deferred items (ADR-0042 to ADR-0044, v3.13). This inventory covers what neither
read: the v2-era ADRs' non-goal sections, the CHANGELOG's gap, limitation, deferral
and still-open sections from v2.0.0 to v3.13.0, and the open questions of
`nowandfuture.md` and the strategy-runtime design. Each section is one `HIS-xxx`
ledger entry; each item its own row below.

**257 items in 39 sections:** DELIVERED 115, FIXED-v4 1, BOUNDARY 80, LIMITATION 10, EXTERNAL 9, REMOVED 14, EXPIRED 17, SUPERSEDED 9, FUTURE 2 -- 257 in all. Every one is history the pre-v4 inventory
had not read; what v4.0 itself wrote about them is prose beside the lists, not
an item in them.

| Status | Meaning |
| --- | --- |
| DELIVERED | built in a later release; the evidence names it |
| FIXED-v4 | a defect the item concealed, fixed in v4.0 with a regression test |
| BOUNDARY | kept out on purpose, with the reason the ledger entry gives |
| LIMITATION | kept as a stated limitation, with its reason |
| EXTERNAL | real, and the host application's or a vendor's to supply |
| REMOVED | the thing the item was about left the library |
